# 🗼 タワーディフェンスゲーム

ブラウザで遊べる簡易タワーディフェンスゲームです。  
タワーを配置して押し寄せる敵を撃退し、拠点を守り抜きましょう！

---

## 🎮 ゲームの概要

- **グリッドマップ**（6行 × 10列）上にタワーを配置して、経路を進んでくる敵を倒します
- 敵がゴールに到達するとHP（ライフ）が減少します
- HPが0になるとゲームオーバーです
- 全ウェーブをクリアするとゲームクリアです
- ゲーム終了後にスコアを登録してランキングを確認できます

---

## 🚀 起動方法

### 初回セットアップ

`run_setup.bat` をダブルクリックして実行してください。  
Python の仮想環境の作成と必要なパッケージのインストールが自動で行われます。

```
run_setup.bat
```

### ゲーム起動

`run_app.bat` をダブルクリックして実行してください。

```
run_app.bat
```

起動後、ブラウザで以下のURLにアクセスしてください。

```
http://localhost:5000
```

---

## 🕹️ 遊び方

### 基本の流れ

1. **タワーを選択する**  
   画面下部のボタンから配置したいタワーの種類を選びます

2. **タワーを配置する**  
   マップ上の緑色のマス（経路以外）をクリックしてタワーを配置します  
   ※ 経路（茶色のマス）には配置できません

3. **ウェーブを開始する**  
   「ウェーブ開始」ボタンをクリックすると敵が出現します

4. **敵を全滅させる**  
   タワーが自動で攻撃します。全敵を倒すとウェーブクリアです

5. **繰り返す**  
   次のウェーブに備えてタワーを追加配置し、再度ウェーブを開始します

---

## 🗼 タワーの種類

| タワー | コスト | 特徴 |
|--------|--------|------|
| 🗼 通常タワー | 20G | 単体攻撃・バランス型 |
| 💥 範囲タワー | 30G | 範囲内の複数の敵を同時攻撃・低威力 |
| ❄️ スロータワー | 25G | 敵の移動速度を低下させる |

---

## 👾 敵の種類

| 敵 | HP | 速度 | 特徴 |
|----|-----|------|------|
| 通常敵 | 中 | 中 | バランス型の標準的な敵 |
| 高速敵 | 低 | 高 | 素早く動くが倒しやすい |
| タンク敵 | 高 | 低 | 動きは遅いが非常に頑丈 |

---

## 📊 ステータス

| 項目 | 説明 |
|------|------|
| **Gold** | タワー配置に使用するお金。敵を倒すと獲得できます |
| **HP** | 拠点のライフ。敵がゴールに到達すると減少します |
| **Wave** | 現在のウェーブ数。全5ウェーブあります |
| **Score** | 現在のスコア。敵を倒したりウェーブをクリアすると増加します |

---

## 🏆 スコアとランキング

- ゲーム終了後（ゲームオーバー・ゲームクリア）にスコア登録画面が表示されます
- プレイヤー名を入力して「スコアを保存」ボタンを押すとランキングに登録されます
- 「ランキングを見る」ボタンでスコア上位10名のランキングを確認できます

---

## ⚠️ 注意事項

- シングルプレイ専用です
- セーブ機能はありません（スコアの保存のみ対応）
- ゲームを再起動するとタワーの配置はリセットされます
