# 要件定義書：簡易タワーディフェンスゲーム（Web＋DB）

***

## 1. 概要

### 1.1 システム概要

本システムはブラウザ上で動作する簡易タワーディフェンスゲームである。  
ユーザーはタワーを配置し、進行してくる敵を攻撃して拠点を防衛する。

### 1.2 目的

* Webアプリケーション開発の習得
* JavaScriptによるゲームロジック実装
* Python（Flask）とSQLiteによるデータ管理

***

## 2. システム構成

| 項目      | 内容                      |
| ------- | ----------------------- |
| フロントエンド | JavaScript / HTML / CSS |
| バックエンド  | Python（Flask）           |
| データベース  | SQLite                  |

***

## 3. 機能要件

### 3.1 ゲーム機能

#### 3.1.1 マップ表示

* グリッド形式（6行 × 10列）
* 一本道の経路を固定表示
* 経路は視覚的に区別する

#### 3.1.2 タワー配置

* ユーザーがタワーを選択して配置可能
* 経路上への配置は禁止
* 同一マスへの複数配置は禁止

#### 3.1.3 タワー種類

以下の3種類を実装する：

| 種類     | 特徴        |
| ------ | --------- |
| 通常タワー  | 単体攻撃・平均性能 |
| 範囲タワー  | 複数敵攻撃・低威力 |
| スロータワー | 速度低下効果    |

***

#### 3.1.4 敵の挙動

複数種類の敵を実装する：

| 種類   | HP | 速度 |
| ---- | -- | -- |
| 通常敵  | 中  | 中  |
| 高速敵  | 低  | 高  |
| タンク敵 | 高  | 低  |

* 敵は経路に沿って移動する
* タワーの攻撃を受ける

***

#### 3.1.5 戦闘処理

* 一定間隔でゲームループを実行
* タワーは範囲内の敵を攻撃
* HPが0になった敵は消滅

***

#### 3.1.6 勝敗条件

* 初期HPを設定（例：10）
* 敵がゴールに到達するとHP減少
* HP0でゲーム終了

***

### 3.2 UI機能

#### 3.2.1 画面構成

* タイトル
* ゲームマップ
* ステータス表示
* タワー選択エリア

#### 3.2.2 ステータス表示

表示項目：

* 所持金
* HP
* ウェーブ数

#### 3.2.3 タワー選択UI

* ボタンで選択可能
* 選択中の状態を視覚的に表示

***

### 3.3 スコア管理

#### 3.3.1 スコア保存

* ゲーム終了時にスコア保存
* プレイヤー名とスコアを記録

#### 3.3.2 ランキング表示

* スコアの高い順に表示

***

## 4. 非機能要件

### 4.1 デザイン要件

* 視認性の高いUI
* 明るくさわやかな配色

#### カラー仕様

* メインカラー：#4FC3F7
* 背景：#E1F5FE
* サブカラー：#81C784
* アクセント：#FFF176

***

### 4.2 操作性

* クリック操作のみで完結
* 直感的なUI配置
* 誤操作防止（無効配置制御）

***

### 4.3 パフォーマンス

* ゲームループは100ms間隔で実行

***

## 5. データベース設計

### 5.1 テーブル：scores

```sql
CREATE TABLE scores (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  player_name TEXT,
  score INTEGER,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```
